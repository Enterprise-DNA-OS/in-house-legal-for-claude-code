# Everything that needs a decision now, in priority order

Run `node scripts/legal.mjs attention --json`. Priority 1 is compliance, key dates and contract notice deadlines; 2 is untriaged requests, overdue or missing next steps, budget and workload; 3 is quiet matters, disputed invoices and panel dates. Present by priority with the record reference. Say plainly when nothing is flagged.

Start from the command output, never memory. Use record references in the answer.

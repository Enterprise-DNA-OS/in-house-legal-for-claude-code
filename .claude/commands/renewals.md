# Contracts ending in the next year and their notice deadlines

Run `node scripts/legal.mjs renewals --json`. For each auto-renewing contract, state the notice-by date (end date less notice days), days from today, annual value and the renewal decision. Missing decisions with a notice date inside 90 days go first.

Start from the command output, never memory. Use record references in the answer.

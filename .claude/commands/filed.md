# Record that a company filing is done

After the operator confirms the return or review is filed, run `node scripts/legal.mjs filed <entity> [--date=YYYY-MM-DD]`. A filing counts for the period it falls in: a New Zealand return in or after the filing month, an Australian review on or after the review date.

Start from the command output, never memory. Use record references in the answer.

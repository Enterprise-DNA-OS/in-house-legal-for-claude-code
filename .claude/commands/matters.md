# Open matters, highest risk first, with next steps and last activity

Run `node scripts/legal.mjs matters --json`. Group by risk. For each, give the owner, the next step and when it is due, and the last note date. Call out any step already overdue and any matter with no next step.

Start from the command output, never memory. Use record references in the answer.

# The legal report for the board or executive

Run `node scripts/legal.mjs board-report --json`: demand and spend by business unit, high-risk matters, key dates in the next 90 days, outside counsel spend and compliance flags. Write it for directors: no internal jargon, every number from the output.

Start from the command output, never memory. Use record references in the answer.

# The Monday legal team review, from three commands

Run `node scripts/legal.mjs weekly-review --json`. It returns attention, requests waiting and workload. Write the review in three parts: what must happen this week (with owners), what came in from the business, and who is overloaded. Offer `/draft-weekly-review` to save it.

Start from the command output, never memory. Use record references in the answer.

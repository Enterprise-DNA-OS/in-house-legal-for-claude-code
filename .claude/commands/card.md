# Read one record in full

Run `node scripts/legal.mjs card <type> <ref-or-name> --json`. Types: unit, person, firm, matter, request, date, contract, entity, invoice, cpd, note. When a name matches more than one record, list the candidates and ask.

Start from the command output, never memory. Use record references in the answer.

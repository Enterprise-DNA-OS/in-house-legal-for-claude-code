# CPD hours recorded this year for each lawyer

Run `node scripts/legal.mjs cpd --json`. Show hours against the yearly minimum and whether each lawyer is on pace. Record new CPD with `node scripts/legal.mjs add cpd --ref=D-xx --person=<lawyer> --activity-on=YYYY-MM-DD --activity="..." --hours=1.5`.

Start from the command output, never memory. Use record references in the answer.

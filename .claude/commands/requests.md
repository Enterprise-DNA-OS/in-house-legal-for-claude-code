# Every request from the business: new, triaged, declined or turned into a matter

Run `node scripts/legal.mjs requests --json`. Lead with new requests and how many days each has waited, oldest first. Name the business unit and requester. Say which are past the triage service level in `settings` (triage_days).

Start from the command output, never memory. Use record references in the answer.

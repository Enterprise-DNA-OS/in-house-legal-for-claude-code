# Draft a renewal or non-renewal notice for a contract

Record the decision first with `/renewal`. Then run `node scripts/legal.mjs draft-renewal-notice <contract> --json`. Remind the operator to check the notice clause for how notice must be given. Never send it.

Start from the command output, never memory. Use record references in the answer.
